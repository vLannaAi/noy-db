# @noy-db/in-yjs

[![npm](https://img.shields.io/npm/v/%40noy-db/in-yjs.svg)](https://www.npmjs.com/package/@noy-db/in-yjs)

> Yjs Y.Doc interop for noy-db

Part of [**`@noy-db/hub`**](https://www.npmjs.com/package/@noy-db/hub) — the zero-knowledge, offline-first, encrypted document store.

## Install

```bash
pnpm add @noy-db/hub @noy-db/in-yjs
```

## What it is

Yjs Y.Doc interop for noy-db — collaborative rich-text fields with encrypted-at-rest Yjs state

## Status

**Pre-release** (`0.1.0-pre.1`). API may change before `1.0`.
