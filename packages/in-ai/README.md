# @noy-db/in-ai

[![npm](https://img.shields.io/npm/v/%40noy-db/in-ai.svg)](https://www.npmjs.com/package/@noy-db/in-ai)

> LLM function-calling adapter for noy-db

Part of [**`@noy-db/hub`**](https://www.npmjs.com/package/@noy-db/hub) — the zero-knowledge, offline-first, encrypted document store.

## Install

```bash
pnpm add @noy-db/hub @noy-db/in-ai
```

## What it is

LLM function-calling adapter for noy-db — expose ACL-scoped collections as tool definitions, then dispatch tool calls back to the vault. Format-agnostic (OpenAI, Anthropic, Vercel AI SDK).

## Status

**Pre-release** (`0.1.0-pre.1`). API may change before `1.0`.
