# @noy-db/in-solid

[![npm](https://img.shields.io/npm/v/%40noy-db/in-solid.svg)](https://www.npmjs.com/package/@noy-db/in-solid)

> SolidJS signal primitives for noy-db

Part of [**`@noy-db/hub`**](https://www.npmjs.com/package/@noy-db/hub) — the zero-knowledge, offline-first, encrypted document store.

## Install

```bash
pnpm add @noy-db/hub @noy-db/in-solid
```

## What it is

SolidJS signal primitives for noy-db — createCollectionSignal, createQuerySignal, createSyncSignal backed by noy-db change events.

## Status

**Pre-release** (`0.1.0-pre.1`). API may change before `1.0`.
